# Техническая документация: Бюджетный вертикальный намоточный станок с ЧПУ (v2.0)

## 1. Назначение и общие характеристики
Вертикальный одномоторный намоточный станок предназначен для прецизионной рядовой укладки тонкого обмоточного провода (виток к витку) на бумажные втулки с послойной пропиткой термостойким лаком.

* **Каркас катушки:** бумажная втулка с пропиткой термостойким лаком (`Ø6.2 мм` внутренний диаметр, высота до `20.0 мм`).
* **Базовый провод:** эмальпровод диаметром `0.18 мм`.
* **Базовая намотка:** `340 витков` (`4 слоя` по `85 витков`, расчетная длина намотки `15.3 мм`).
* **Кинематическая схема:** вертикальная башня (ось Z); неподвижный по высоте шпиндель на валу шагового двигателя + подвижная каретка укладчика на ходовом винте М5.
* **Питание:** блок питания постоянного тока `12 В`.

---

## 2. Кинематика и расчет подачи
Шпиндель с оправкой вращается напрямую от вала шагового двигателя **NEMA 17** (`1 оборот двигателя = 1 виток провода`). Подъем и опускание каретки укладчика синхронизированы механически через цилиндрическую прямозубую передачу (`модуль m = 1.0 мм`, межосевое расстояние `49.0 мм`) и ходовой болт **М5 × 40 мм** (`шаг резьбы P = 0.8 мм`).

### Формула шага укладки
$$S = P \times \frac{Z_1}{Z_2}$$

Для базового провода `0.18 мм` используется пара шестерен `18 : 80`:
$$S = 0.8 \times \frac{18}{80} = 0.180\text{ мм/оборот}$$

### Таблица сменных шестерен (без изменения корпуса и болта М5)
При сохранении межосевого расстояния `49.0 мм` (`Z1 + Z2 = 98` при модуле `m = 1.0`) шаг подачи можно изменять в диапазоне **от 0.091 до 0.800 мм/оборот**:

| Шестерня мотора (`Z1`) | Шестерня болта (`Z2`) | Передаточное отношение | Шаг подачи (`мм/оборот`) | Рекомендуемый диаметр провода |
| :---: | :---: | :---: | :---: | :--- |
| 10 | 88 | 1 : 8.80 | **0.091 мм** | 0.08 – 0.09 мм |
| 14 | 84 | 1 : 6.00 | **0.133 мм** | 0.12 – 0.13 мм |
| **18** | **80** | **1 : 4.44** | **0.180 мм** | **0.18 мм (базовый комплект)** |
| 20 | 78 | 1 : 3.90 | **0.205 мм** | 0.20 мм |
| 28 | 70 | 1 : 2.50 | **0.320 мм** | 0.30 – 0.32 мм |
| 38 | 60 | 1 : 1.58 | **0.507 мм** | 0.50 мм |
| 49 | 49 | 1 : 1.00 | **0.800 мм** | 0.80 мм |

## 3. Спецификация комплектующих (BOM)

### 3.1. Электроника
1. **Микроконтроллер:** Arduino Nano V3 (ATmega328P) — 1 шт.
2. **Драйвер шагового двигателя:** TMC2208 (режим Standalone, микрошаг 1/8) с радиатором — 1 шт.
3. **Шаговый двигатель:** NEMA 17 (вал `Ø5 мм` с лыской, шаг `1.8°`) — 1 шт.
4. **Концевые выключатели:** микропереключатели с рычагом (нормально разомкнутые, `NO`) — 2 шт.
5. **Кнопки управления:** тактовые кнопки без фиксации (`NO`) для выбора 3 режимов работы — 3 шт.
6. **Блок питания:** `12 В` (от `1.5 А`) — 1 шт.
7. **Фильтрующий конденсатор:** электролитический `100 мкФ × 25–35 В` — 1 шт.

### 3.2. Стандартные изделия и крепеж
1. **Направляющие:** строительные гвозди `150 × 5 мм` (без шляпок и острия, шлифованные) — 2 шт. (плюс 1 шт. при необходимости для внешних упоров).
2. **Втулки скольжения:** тефлоновая трубка (PTFE) наружным диаметром `6.0 мм`, внутренним `5.2 мм` — 4 отрезка по `12 мм`.
3. **Ходовой винт:** болт `М5 × 40 мм` (шестигранная головка под ключ `8 мм`) — 1 шт.
4. **Ходовая гайка:** гайка `М5` стандартная — 1 шт.
5. **Ось большой шестерни:** стяжной болт из вытяжной заклепки со шляпкой `Ø9.0 мм` (стержень `Ø5.0 мм`) — 1 шт.
6. **Крепеж двигателя:** винты `М3 × 8–10 мм` — 4 шт.
7. **Узел натяжения:** неодимовые магниты (2 пары) + силиконовая прокладка.

## 4. Схема подключения электроники

### 4.1. Распиновка Arduino Nano V3

| Контакт Arduino Nano | Куда подключается | Назначение в схеме |
| :--- | :--- | :--- |
| **D2** | TMC2208 — `DIR` | Направление вращения (подъем / опускание каретки) |
| **D3** | TMC2208 — `STEP` | Импульсы шагов (`1600 шагов = 1 оборот`) |
| **D4** | TMC2208 — `EN` | Включение и удержание мотора (`LOW` = активен) |
| **D6** | Нижний концевик (`NO` → `GND`) | Базовая парковка («ноль») и нижний ограничитель |
| **D7** | Верхний концевик (`NO` → `GND`) | Аварийный ограничитель верхнего хода |
| **D8** | **Кнопка 1** (`NO` → `GND`) | Запуск/продолжение: **Равномерная укладка** |
| **D9** | **Кнопка 2** (`NO` → `GND`) | Запуск/продолжение: **Укладка «горкой»** |
| **D10** | **Кнопка 3** (`NO` → `GND`) | Запуск: **Измерительная катушка (10–20 витков)** |
| **D13** | Встроенный светодиод (`LED_BUILTIN`) | Индикация работы (горит в цикле, мигает в паузе под лак) |
| **5V** | TMC2208 — `VIO` | Питание логики драйвера |
| **GND** | TMC2208 — `GND` + общие контакты кнопок и концевиков | Общая земля схемы |
| **VIN** | Блок питания `+12 В` | Питание платы Arduino |

### 4.2. Настройка драйвера TMC2208 и меры безопасности
1. **Микрошаг:** контакты `MS1` и `MS2` оставить неподключенными — драйвер автоматически включит режим **1/8 микрошага** (`1600 микрошагов/оборот`).
2. **Силовое питание:** `+12 В` подключить к `VM` (рядом с выводами мотора), минус БП — к силовому `GND`. Параллельно `VM` и `GND` максимально близко к драйверу установить конденсатор `100 мкФ × 25–35 В`.
3. **Ток двигателя (`Vref`):** подстроечным резистором на драйвере выставить напряжение `0.7–0.9 В` между винтом потенциометра и `GND`.
4. **Охлаждение:** наклеить алюминиевый радиатор на чип TMC2208 сверху, не замыкая ножки SMD-компонентов.
5. **Запрещено** отключать или подключать разъем шагового двигателя при включенном питании `12 В`.

## 5. Режимы работы и прошивка Arduino Nano V3

### 5.1. Описание трех режимов запуска
1. **Кнопка D8 — Равномерная укладка:** наматывает 4 полных слоя по `85 витков` (`340 витков` всего) с реверсом направления на каждом слое и автоматической остановкой после каждого слоя для пропитки термостойким лаком. Продолжение следующего слоя — повторным нажатием `D8`.
2. **Кнопка D9 — Укладка «горкой» у нижнего торца:** формирует ступенчатую пирамидальную обмотку у нижнего края катушки за счет укороченных двойных проходов вверх от базы и обратно вниз (`80→80`, пауза под лак, `55→55`, пауза под лак, `30→30` витков).
3. **Кнопка D10 — Измерительная катушка:** быстрая намотка пробной катушки в 1 слой (`15 витков` по умолчанию, настраивается в диапазоне `10–20 витков`) без промежуточных пауз.

Во время всех технологических пауз под пропитку лаком двигатель остается под удержанием (`EN = LOW`), предотвращая проворачивание оправки и ослабление натяжения провода `0.18 мм`.

### 5.2. Исходный код прошивки (`winding_machine.ino`)

```cpp
// === РАСПИНОВКА ===
const int PIN_DIR       = 2;
const int PIN_STEP      = 3;
const int PIN_EN        = 4;

const int PIN_LIM_DOWN  = 6;  // Нижний концевик (база)
const int PIN_LIM_UP    = 7;  // Верхний концевик (авария)

const int PIN_BTN_UNIF  = 8;  // Режим 1: Равномерная укладка
const int PIN_BTN_MOUND = 9;  // Режим 2: Укладка "горкой"
const int PIN_BTN_TEST  = 10; // Режим 3: Измерительная катушка
const int PIN_LED       = 13;

// === НАСТРОЙКИ МЕХАНИКИ И СКОРОСТИ ===
const long STEPS_PER_REV = 1600; // 200 шагов * 8 микрошагов (TMC2208 MS1/MS2 висят в воздухе)
const bool DIR_UP        = HIGH; // Если при DIR_UP каретка едет вниз — поменяй HIGH на LOW
const bool DIR_DOWN      = LOW;

const int SPEED_MAX_US   = 450;  // Макс. скорость (~1.4 об/сек, чем меньше число — тем быстрее)
const int SPEED_START_US = 1600; // Начальная скорость плавного разгона
const int RAMP_STEPS     = 400;  // Длина плавного разгона/торможения в микрошагах (1/4 оборота)

// === ПАРАМЕТРЫ ПРОГРАММ НАМОТКИ ===
// Режим 1: Равномерная (4 слоя по 85 витков = 340 витков)
const int UNIFORM_LAYERS = 4;
const int UNIFORM_TURNS[UNIFORM_LAYERS] = {85, 85, 85, 85};

// Режим 2: "Горка" у нижнего торца (идет вверх и обратно к нижнему торцу, уменьшая высоту)
const int MOUND_LAYERS = 6;
const int MOUND_TURNS[MOUND_LAYERS] = {80, 80, 55, 55, 30, 30};

// Режим 3: Измерительная катушка (10-20 витков)
const int TEST_TURNS = 15;

void setup() {
  Serial.begin(115200);
  pinMode(PIN_DIR, OUTPUT);
  pinMode(PIN_STEP, OUTPUT);
  pinMode(PIN_EN, OUTPUT);
  pinMode(PIN_LED, OUTPUT);

  pinMode(PIN_LIM_DOWN, INPUT_PULLUP);
  pinMode(PIN_LIM_UP, INPUT_PULLUP);
  pinMode(PIN_BTN_UNIF, INPUT_PULLUP);
  pinMode(PIN_BTN_MOUND, INPUT_PULLUP);
  pinMode(PIN_BTN_TEST, INPUT_PULLUP);

  // Отключаем удержание мотора при включении, чтобы можно было поправить каретку рукой
  digitalWrite(PIN_EN, HIGH);
  Serial.println(F("Stanok gotov. Vyberite rezhim (D8, D9 ili D10)."));
}

void loop() {
  if (isPressed(PIN_BTN_UNIF)) {
    runMultiLayerMode("RAVNOMERNAYA UKLADKA", UNIFORM_TURNS, UNIFORM_LAYERS, PIN_BTN_UNIF);
  }
  else if (isPressed(PIN_BTN_MOUND)) {
    runMultiLayerMode("UKLADKA GORKOY", MOUND_TURNS, MOUND_LAYERS, PIN_BTN_MOUND);
  }
  else if (isPressed(PIN_BTN_TEST)) {
    runTestCoilMode();
  }
}

// === РЕЖИМ 1 И РЕЖИМ 2: МНОГОСЛОЙНАЯ НАМОТКА С ПАУЗАМИ ПОД ЛАК ===
void runMultiLayerMode(const char* modeName, const int turnsArray[], int totalLayers, int activeBtnPin) {
  Serial.print(F("Start rezhima: "));
  Serial.println(modeName);

  digitalWrite(PIN_EN, LOW); // Включаем удержание вала
  homeToBottom();            // Паркуемся на нижний концевик

  for (int layer = 0; layer < totalLayers; layer++) {
    bool goingUp = (layer % 2 == 0); // Четные индексы (0, 2, 4...) вверх, нечетные (1, 3, 5...) вниз
    long stepsToMove = (long)turnsArray[layer] * STEPS_PER_REV;

    Serial.print(F("Sloy ")); Serial.print(layer + 1);
    Serial.print(F(" iz ")); Serial.print(totalLayers);
    Serial.print(F(" | Vitkov: ")); Serial.println(turnsArray[layer]);

    digitalWrite(PIN_LED, HIGH);
    if (!moveSteps(stepsToMove, goingUp, true)) {
      abortEmergency();
      return;
    }

    // Если это не последний слой — ждем пропитку лаком и повторное нажатие кнопки режима
    if (layer < totalLayers - 1) {
      Serial.println(F("PAUZA: propitayte sloy lakom i nazhmite knopku rezhima dlya prodolzheniya..."));
      waitForContinue(activeBtnPin);
    }
  }

  finishCycle();
}

// === РЕЖИМ 3: ИЗМЕРИТЕЛЬНАЯ КАТУШКА (10-20 ВИТКОВ) ===
void runTestCoilMode() {
  Serial.println(F("Start rezhima: IZMERITELNAYA KATUSHKA"));
  digitalWrite(PIN_EN, LOW);
  homeToBottom();

  digitalWrite(PIN_LED, HIGH);
  long stepsToMove = (long)TEST_TURNS * STEPS_PER_REV;
  if (!moveSteps(stepsToMove, true, true)) {
    abortEmergency();
    return;
  }

  finishCycle();
}

// === ПАРКОВКА ПО НИЖНЕМУ КОНЦЕВИКУ (D6) ===
void homeToBottom() {
  Serial.println(F("Parkovka v nol..."));
  digitalWrite(PIN_DIR, DIR_DOWN);
  while (digitalRead(PIN_LIM_DOWN) == HIGH) {
    stepPulse(900);
  }
  delay(150);
  // Отъезжаем вверх на 1/4 оборота, чтобы отпустить микрик концевика
  digitalWrite(PIN_DIR, DIR_UP);
  for (int i = 0; i < 400; i++) {
    stepPulse(900);
  }
  delay(200);
}

// === ДВИЖЕНИЕ С ПЛАВНЫМ РАЗГОНОМ, ТОРМОЖЕНИЕМ И ЗАЩИТОЙ ПО КОНЦЕВИКАМ ===
bool moveSteps(long totalSteps, bool up, bool checkLimits) {
  digitalWrite(PIN_DIR, up ? DIR_UP : DIR_DOWN);

  for (long i = 0; i < totalSteps; i++) {
    if (checkLimits) {
      if (up && digitalRead(PIN_LIM_UP) == LOW) return false;
      if (!up && digitalRead(PIN_LIM_DOWN) == LOW) return false;
    }

    int currentDelay = SPEED_MAX_US;
    if (i < RAMP_STEPS) {
      currentDelay = map(i, 0, RAMP_STEPS, SPEED_START_US, SPEED_MAX_US);
    } else if (totalSteps - i < RAMP_STEPS) {
      currentDelay = map(totalSteps - i, 0, RAMP_STEPS, SPEED_START_US, SPEED_MAX_US);
    }

    stepPulse(currentDelay);
  }
  return true;
}

void stepPulse(int delayUs) {
  digitalWrite(PIN_STEP, HIGH);
  delayMicroseconds(5);
  digitalWrite(PIN_STEP, LOW);
  delayMicroseconds(delayUs);
}

// === ОЖИДАНИЕ ПРОДОЛЖЕНИЯ ПОСЛЕ ПРОПИТКИ ЛАКОМ (МОТОР УДЕРЖИВАЕТ НАТЯЖЕНИЕ) ===
void waitForContinue(int btnPin) {
  unsigned long prevMillis = 0;
  bool ledState = false;

  while (true) {
    if (millis() - prevMillis >= 250) {
      prevMillis = millis();
      ledState = !ledState;
      digitalWrite(PIN_LED, ledState);
    }
    if (isPressed(btnPin)) {
      delay(300);
      return;
    }
  }
}

bool isPressed(int pin) {
  if (digitalRead(pin) == LOW) {
    delay(40);
    if (digitalRead(pin) == LOW) {
      while (digitalRead(pin) == LOW) {}
      return true;
    }
  }
  return false;
}

void finishCycle() {
  digitalWrite(PIN_LED, LOW);
  Serial.println(F("Namotka zavershena! Uderzhanie vala aktivno 5 sek..."));
  delay(5000);
  digitalWrite(PIN_EN, HIGH);
}

void abortEmergency() {
  digitalWrite(PIN_LED, LOW);
  digitalWrite(PIN_EN, HIGH);
  Serial.println(F("AVARIYA: srabotal koncevnik! Stanok ostanovlen."));
  while (true) {
    digitalWrite(PIN_LED, !digitalRead(PIN_LED));
    delay(100);
  }
}
```
