## 💡 Краткое описание

**PDA Muscle (ЭМВ)** — это гибкий линейный шагово-волновой привод, имитирующий работу скелетных мышц человека:
1. **Бегущая электромагнитная волна:** цепочка из нескольких магнитомягких стальных сегментов, связанных кевларовой нитью с зазорами, перемещается внутри тонкостенной фторопластовой (`PTFE`) трубки магнитным полем последовательно переключаемых катушек.
2. **Бессенсорный контроль положения:** индуктивность каждой катушки измеряется в реальном времени по скорости нарастания тока (\(\frac{dI}{dt}\)) на токовом шунте `0,10 Ом`, что позволяет определять положение сердечника без внешних энкодеров.
3. **Пассивная механическая защёлка (`0,00 А`):** в конце рабочего хода тросик удерживается односторонней защёлкой без потребления энергии, а снятие фиксации выполняется отдельной катушкой сброса (`K6`).
